# 公式サイトへのチャット設置手順

所要時間 **20〜25分**。追加するのは **1行だけ** です。

## 事前確認（プレビュー）

先にここで動きを見てください。実際のサイトには何も起きません。

**https://kizuchiro7-ops.github.io/kizu-ai/chiro-public/preview.html**

右下の「ご質問はこちら」を押すと、設置後と同じチャットが開きます。
スマホでは全画面、パソコンでは右下のパネルで開きます。

---

## 1. バックアップを取る（必ず最初に）

制作会社に連絡が取れない状態なので、**戻せる状態を作ってから**触ります。

1. WordPress管理画面 → **外観** → **テーマの編集**
2. 右側のファイル一覧から **`footer.php`**（テーマフッター）を選ぶ
3. 表示された中身を**すべて選択してコピー**
4. デスクトップに `footer_backup.txt` として貼り付けて保存

これで、何かあっても貼り戻せます。

## 2. 1行を追加する

`footer.php` の中から **`</body>`** という行を探します（たいてい一番下のほうです）。

その **すぐ上** の行に、これを貼り付けます。

```html
<script src="https://kizuchiro7-ops.github.io/kizu-ai/chiro-public/widget.js" defer></script>
```

こういう並びになります。

```html
<script src="https://kizuchiro7-ops.github.io/kizu-ai/chiro-public/widget.js" defer></script>
</body>
</html>
```

**「ファイルを更新」** を押します。

> WordPress 4.9 にはテーマ編集の構文チェックと自動ロールバックが入っています。
> 致命的なエラーが出た場合は保存が拒否され、元に戻ります。

## 3. 表示を確認する

1. https://www.kizuchiro.com/ を開く（**スーパーリロード**：Macは `Cmd+Shift+R`）
2. 右下に緑の「ご質問はこちら」が出るか
3. 押すとチャットが開くか
4. 「施術料金はいくらですか？」を押して、返事が来るか
5. **スマホでも同じことを確認**（全画面で開きます）

## 4. もし表示が崩れたら

`footer.php` に戻り、追加した1行を消して「ファイルを更新」。
それでも直らないときは、`footer_backup.txt` の中身を全部貼り戻します。

---

## 覚えておいていただきたいこと

- **チャットの中身を直すのに、サイトを触る必要はありません。**
  回答の内容・料金・定例質問の変更は、すべてこちら側で完結します。
  サイトに貼るのはこの1行きりで、以後は変わりません。
- **テーマを更新すると、この1行は消えます。** 表示されなくなったら、
  手順2をもう一度やってください。
- チャットを止めたいときは、この1行を消すだけです。
